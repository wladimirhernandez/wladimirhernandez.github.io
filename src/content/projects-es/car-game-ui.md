Un menú animado para un juego de carreras, hecho con el SDK nativo de NoesisGUI en C++: XAML para la parte visual y ViewModels en C++ para el estado y la entrada.

El menú principal tiene pestañas de secciones, un carrusel de modos de juego que se desliza hasta la selección y modos bloqueados. La pantalla de selección de vehículo muestra cada auto con un panel de estadísticas y una tira de miniaturas. Las indicaciones en pantalla cambian entre teclas y botones de mando según el último dispositivo usado.

El diseño sigue el concepto de Dribbble [Racing game interface concept](https://dribbble.com/shots/24405015-Racing-game-interface-concept); el código, los textos y el logo son míos, y todas las fotos son CC0.
