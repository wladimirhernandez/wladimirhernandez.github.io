An animated racing game menu built with the NoesisGUI native C++ SDK: XAML for the visuals, C++ ViewModels for state and input.

The main menu has section tabs, a game-mode carousel that slides to the selection and locked modes. The vehicle select screen shows each car with a stats panel and a thumbnail strip. Input hints switch between keyboard keys and gamepad buttons depending on the last device used.

The layout follows the Dribbble concept [Racing game interface concept](https://dribbble.com/shots/24405015-Racing-game-interface-concept); the code, the copy and the logo are my own, and all photos are CC0.
